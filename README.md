# Creative Bakery Landing Page

Creative Bakery is a modern, responsive landing page for a pastry workshop. This project demonstrates proficiency in coding complex layouts, using BEM methodology, and optimizing web page performance.

## [Live Preview]()

## Design Reference

[Creative Bakery Design](https://www.figma.com/design/dY3izAm0Vspsmra4lQWQIP/Bakerlab_FE-students?node-id=11342-1117&p=f&t=gZvWtkb6RN7TLv8h-0)

## Technologies Used

- **HTML5** - semantic markup.
- **SCSS** - utilizing variables, mixins, and nesting for clean, maintainable code.
- **BEM Methodology** - for a clear and scalable class structure.
- **CSS Grid & Flexbox**- used to create a flexible and adaptive grid system.
- **Parcel** - build tool for fast bundling and project optimization.
- **JavaScript** - implemented for mobile menu functionality.

## Key Features

- **Fully Responsive:** The website renders correctly across all devices (Desktop, Tablet, Mobile).
- **Pixel Perfect:** Strict adherence to the provided Figma design.
- **Interactive Elements:** scrolling to sections, custom hover effects, and a functional mobile menu.

## Getting Started

To run this project locally, follow these steps:

1. Clone the repository:
```bash
git clone [https://github.com/Roma-Ivashchenko/creative-bakery-website.git](https://github.com/Roma-Ivashchenko/creative-bakery-website.git)

2. Navigate to the project directory:

cd creative-bakery-website

3. Install dependencies:

npm install

4. Start the local development server:

npm start
